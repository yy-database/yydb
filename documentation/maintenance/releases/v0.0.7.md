# v0.0.7

The crate split behind today's layering (`yydb-engine`, `yydb-storage`, `yydb-protocol`, `yydb-query`), per-peer sessions, and the first `@yydb/light-db` interface.

## Features

- Add the `Database` KV and schema surface to `@yydb/light-db` ([@aster](https://github.com/aster))
- Give every serve peer an isolated `Connection::session` over one shared store ([@aster](https://github.com/aster))
- Add `yydb-query` catalog module ([@aster](https://github.com/aster))
- Wire `yydb-query` into `Connection` transaction path ([@aster](https://github.com/aster))

## Bug Fixes

- Repair `@yydb/light-db` index lookup, transaction rollback and snapshot persistence ([@aster](https://github.com/aster))
- Open `.light` on demand and keep `LSN` monotonic across checkpoints ([@aster](https://github.com/aster))
- Compute the SHM header checksum when serializing ([@aster](https://github.com/aster))
- Buffer `WalReader` records across refills instead of discarding the read chunk ([@aster](https://github.com/aster))
- Fix `@yydb/light-db` record, page and snapshot serialization ([@aster](https://github.com/aster))
- Remove the temporary `reshape-rust` migration script ([@aster](https://github.com/aster))
