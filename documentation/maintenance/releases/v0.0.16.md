# v0.0.16

Browser and wasm author-side isomorphism: `BrowserDatabase` becomes `Database`, the wasm handle becomes `WasmDatabase`, and release and CI fixes land.

## Bug Fixes

- Browser multitab test uses duck typing for `LightDbError` to avoid `instanceof` mismatch ([@aster](https://github.com/aster))
- Browser test uses duck typing for `LightDbError` to avoid `instanceof` mismatch across transpile boundaries ([@aster](https://github.com/aster))
- Remove `nifty format --check` from TypeScript CI gate ([@aster](https://github.com/aster))

## Other

- Fix release publish step and rewrite all `workspace:*` deps with `@yydb/yydb` before `@yydb/yydb-client` ([@aster](https://github.com/aster))
- Rename `BrowserDatabase` to `Database` and demote `WASM` `Database` to `WasmDatabase` for author side isomorphism ([@aster](https://github.com/aster))
- Browser multitab test imports leaf modules directly to bypass `WASM` reexport chain ([@aster](https://github.com/aster))
- Browser test imports leaf modules directly to bypass `WASM` reexport chain ([@aster](https://github.com/aster))
- Split `WASM` `Database` from pure TypeScript `BrowserDatabase` to avoid `wasm32` specifier in browser tests ([@aster](https://github.com/aster))
- Restore `BrowserDatabase` pure TypeScript path alongside `WASM` `Database` ([@aster](https://github.com/aster))
- Fix `@yydb/light-db` tests to use `StorageEngine` and add browser-safe vite aliases ([@aster](https://github.com/aster))
- Build `@yydb/yydb` before `@yydb/yydb-client` in TypeScript CI ([@aster](https://github.com/aster))
