# v0.0.8

`@yydb/light-db` becomes the browser-native TypeScript product, with OPFS and IndexedDB backends and a real-browser conformance suite.

## Features

- Add the `IndexedDB` storage adapter for the browser product ([@aster](https://github.com/aster))
- Rebuild `@yydb/light-db` as a browser-native YYDB implementation ([@aster](https://github.com/aster))

## Other

- Document `@yydb/light-db` as the browser product and run its suites in CI ([@aster](https://github.com/aster))
- Apply the repository formatter to `@yydb/light-db` ([@aster](https://github.com/aster))
- Keep `@yydb/light-db` free of host ambient types and Node test helpers ([@aster](https://github.com/aster))
- Cover `@yydb/light-db` with a real-browser conformance suite ([@aster](https://github.com/aster))
