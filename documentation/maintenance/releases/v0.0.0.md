# v0.0.0

Project foundation: typed contracts in `yydb-types`, batched records, leases, TTL and namespace quotas, object attachment, doctor checks, and validated UDF execution.

## Features

- Run validated execution UDFs in `yydb` ([@aster](https://github.com/aster))
- Add typed VOS-ready UDF contracts ([@aster](https://github.com/aster))
- Add `DoctorReport` types to `yydb-types` ([@aster](https://github.com/aster))
- Add `ReclaimReport` to `yydb-types` ([@aster](https://github.com/aster))
- Add TTL and namespace quota types to `yydb-types` ([@aster](https://github.com/aster))
- Add lease and CAS error types to `yydb-types` ([@aster](https://github.com/aster))
