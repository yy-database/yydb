# v0.0.3

`Connection` reads and writes `YDPG` pages through `FilePager`, with a B+ tree, slotted leaves, WAL persistence, and a doctor probe.

## Features

- Wire `Connection` to `YDPG` and `FilePager` ([@aster](https://github.com/aster))
- Add full-tree scan and WAL toggles to `RecordTree` in `yydb-format` ([@aster](https://github.com/aster))
- Add `FilePager` and `YYWL` WAL persistence to `yydb-format` ([@aster](https://github.com/aster))
- Wire leaf split and internal-node B+ tree routing in `yydb-format` ([@aster](https://github.com/aster))
- Implement slotted leaf and `MemoryPager` KV put/get in `yydb-format` ([@aster](https://github.com/aster))

## Other

- Add `YDPG` doctor probe to `yydb-format` ([@aster](https://github.com/aster))
- Add `YDPG` golden bytes contract tests ([@aster](https://github.com/aster))
