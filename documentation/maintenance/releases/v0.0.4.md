# v0.0.4

Browser wasm sessions and the `@yydb/yydb-unknown-wasm32` package, YDPG-only file open, and removal of the legacy `YYWL` snapshot journal.

## Features

- Wire `@yydb/yydb/wasm` `Database` to wasm sessions ([@aster](https://github.com/aster))
- Add KV and schema methods to `yydb-wasm` sessions ([@aster](https://github.com/aster))
- Add `@yydb/yydb` wasm entry under `src/wasm` ([@aster](https://github.com/aster))
- Add `build:wasm` and `@yydb/yydb-unknown-wasm32` package skeleton ([@aster](https://github.com/aster))

## Bug Fixes

- Fix CI by tracking format fixture reference and aligning nifty.config.ts ([@aster](https://github.com/aster))
- Remove `yydb generate` and `@yydb/yydb/generator` ([@aster](https://github.com/aster))
- Make `Connection::open` accept only `YDPG` and unify on `FilePager` ([@aster](https://github.com/aster))
- Fix macOS `flock` unsafe call ([@aster](https://github.com/aster))

## Other

- Document `@yydb/yydb` isomorphic exports and wasm entry ([@aster](https://github.com/aster))
- Restructure @yydb/yydb into src/node and src/shared ([@aster](https://github.com/aster))
- Rewrite READMEs and Agent Skills for npm positioning and non-ORM clarity ([@aster](https://github.com/aster))
- Align YDPG-only contract tests and WAL smoke assertions ([@aster](https://github.com/aster))
- Remove legacy whole-state `YYWL` snapshot journal ([@aster](https://github.com/aster))
- Pin `@yydb/yydb-*` platform `lib/` binding names and add `build:napi` ([@aster](https://github.com/aster))
- Run `rustfmt` on `yydb-format`, `yydb-wasm`, and `yydb` ([@aster](https://github.com/aster))
- Add cross-process writer lock and `YDPG` doctor to `Connection` ([@aster](https://github.com/aster))
