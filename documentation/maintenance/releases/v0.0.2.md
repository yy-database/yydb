## Features

- Add `yydb-format` parser for `YDPG` pages and `YYWL` WAL ([@aster](https://github.com/aster))
- Add `PersistentSession` OPFS session skeleton to `yydb-wasm` ([@aster](https://github.com/aster))
- Wire OPFS logical I/O and `OpfsPersistentVolume` in `yydb-wasm` ([@aster](https://github.com/aster))
- Keep crash-after-publish OPFS blobs as orphans ([@aster](https://github.com/aster))
- Abort OPFS generation publish on quota overflow ([@aster](https://github.com/aster))
- Reject second OPFS writer with `Error::LeaseUnavailable` ([@aster](https://github.com/aster))
- Add OPFS capability probing to `yydb-wasm` ([@aster](https://github.com/aster))
- Add `Connection::open_yydx` with sibling `-objects` blob root ([@aster](https://github.com/aster))
