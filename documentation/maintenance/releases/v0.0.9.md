Wasm sessions gain transactions, delete, and checkpoint. N-API adds `Client` and micro host methods, and `Database` talks to N-API directly.

## Features

- Add transaction, delete and checkpoint to both `WASM` session types ([@aster](https://github.com/aster))
- Add `Client` struct and `Database` micro host methods in `yydb-napi` ([@aster](https://github.com/aster))
