# v0.0.17

Release pipeline hardening for `darwin-x64` and a standalone error contract in `@yydb/yydb-client`.

## Other

- Drop `continue-on-error` and build `darwin-x64` on `macos-latest` arm64 runner with Tier 2 cross compile and clang ([@aster](https://github.com/aster))
- Release resilience: `darwin-x64` continues on timeout, download/prepare/publish steps tolerate missing native binaries ([@aster](https://github.com/aster))
- Decouple `@yydb/yydb-client` from `@yydb/yydb` to own the error contract locally ([@aster](https://github.com/aster))
