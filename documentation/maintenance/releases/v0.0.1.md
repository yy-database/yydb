The first end-to-end release: VOS query and DML execution, the TypeScript CLI over N-API, micro UDFs on the wire, Python bindings, and the `@yydb/yydb-skills` package.

## Features

- Add `@yydb/yydb-skills` integrator Agent Skills package ([@aster](https://github.com/aster))
- Add `yydb-pyo3` Python binding crate ([@aster](https://github.com/aster))
- Simplify schema API with document-driven versioning ([@aster](https://github.com/aster))
- Support nested reference projection in VOS query `map` ([@aster](https://github.com/aster))
- Resolve reference field paths in VOS query filters ([@aster](https://github.com/aster))
- Split wire serve into `yydb-server` crate ([@aster](https://github.com/aster))
- Extend VOS execute for static insert and schema macros ([@aster](https://github.com/aster))
- Add data transactions on `Connection` ([@aster](https://github.com/aster))
- Add VOS insert execute on `Connection` ([@aster](https://github.com/aster))
- Add VOS read query executor on `Connection` ([@aster](https://github.com/aster))
- Rebuild `yydb` CLI on `@vmz/commander` with `generate` ([@aster](https://github.com/aster))
- Add VOS subset generator for `yydb generate` ([@aster](https://github.com/aster))
- Route `@yydb/yydb` `Database` through the TS CLI and micro wire host ([@aster](https://github.com/aster))
- Add TypeScript `yydb` CLI backed by `yydb-napi` ([@aster](https://github.com/aster))
- Add `MicroHostInvoke` and `ScalarCall` to YY wire clients ([@aster](https://github.com/aster))
- Add `yydb-napi` and move `serve` into the `yydb` library ([@aster](https://github.com/aster))
- Sync `@yydb/yydb` `registerMicro` metadata to the private engine ([@aster](https://github.com/aster))
- Add `MicroRegister` to YY wire client and serve protocol docs ([@aster](https://github.com/aster))
- Wire embedded TS micro registration and `MicroRegister` serve dispatch ([@aster](https://github.com/aster))
- Add TypeScript micro builder and session removal in `yydb-udf` ([@aster](https://github.com/aster))
- Add `defineMicro` and `registerMicro` to `@yydb/yydb` ([@aster](https://github.com/aster))
- Route VOS macro and native scalars through `yydb-udf` session and catalog ([@aster](https://github.com/aster))
- Add `yydb-udf` contract, registry, and host adapters ([@aster](https://github.com/aster))
- Lower Oak VOS scalars into `yydb` execution ([@aster](https://github.com/aster))
- Persist `yydb` VOS catalog identity ([@aster](https://github.com/aster))
- Bind initial VOS catalog identities to `yy-execution` ([@aster](https://github.com/aster))
- Bind record reads to typed field handles ([@aster](https://github.com/aster))
- Add schema-identified record field execution ([@aster](https://github.com/aster))
- Extend `yy-execution` values for `file` and `vec` ([@aster](https://github.com/aster))
