# v0.0.14

`verify` and `info --doctor` in the CLI, backup, doctor, and compact on N-API and the Node facade, plus prepared-statement groundwork.

## Features

- Add `verify` command and `info --doctor` with diagnostic error rendering ([@aster](https://github.com/aster))
- Add backup, doctor and compact to N-API and the Node facade ([@aster](https://github.com/aster))
- Add serde `Serialize` for `DoctorReport` and `CompactReport` in `yydb-types` ([@aster](https://github.com/aster))

## Other

- Introduce `BoundValue` and `Slot` to prepare `PreparedStatement` in `yydb-query` ([@aster](https://github.com/aster))
