# YYDB 开发者文档

本目录面向 **修改 YYDB 实现的人**，记录设计准则与不可破坏的合同。它不是产品介绍，也不是路线图。

## 范围

- 产品与数据层不可破坏的不变量
- crate 分层、模块结构、能力归属与依赖方向
- 磁盘格式、线协议与兼容规则
- 代码、测试、CI 与发布的工程门槛
- 面向宿主与绑定作者的 UX / DX 准则

## 非范围

| 内容                       | 位置                                                |
|----------------------------|-----------------------------------------------------|
| 路线图、阶段计划、发布排期 | 不进入仓库；本目录不记录                            |
| 终端用户安装与使用         | `projects/yydb.ts/homepage/documentation/zh-hans/` |
| 单项 API 用法              | 各 crate 的 `readme.md` 与 docs.rs                  |
| 维护者发布操作流程         | `.agents/skills/yydb-release/SKILL.md`              |

## 维护规则

1. 设计准则的变更先改本目录，再改代码。只改代码不改准则视为未完成。
2. 实现与本文冲突时，先判定哪一边是刻意变更：要么修正实现，要么修正本文，不允许两份口径长期并存。
3. 本目录不写内部决策记录路径、不写排期、不写用户教程，避免文档互相引用成网。
4. 新增准则优先并入现有文件；只有在主题无法归属时才新建文件。
