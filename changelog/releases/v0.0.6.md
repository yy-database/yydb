Checkpoint and backup hardening: dual-slot headers, `YYSH` mirroring, `.yydx` compaction and backups, WAL blob-ref frames, and stable wire error codes.

## Features

- Format the TypeScript packages with the Nifty preset ([@aster](https://github.com/aster))
- Give `YYDB` wire errors a stable code and message body ([@aster](https://github.com/aster))
- Fuse the `YYDB` host micro surface with the `@voml/vos` type builders ([@aster](https://github.com/aster))
- File connections expose `main_snapshot` after `checkpoint` ([@aster](https://github.com/aster))
- Add `Connection::compact_yydx` `v0` compaction and `CompactReport` ([@aster](https://github.com/aster))
- Add `Connection::backup_yydx_to` to copy the main file and blob tree after `checkpoint` ([@aster](https://github.com/aster))
- Add `Connection::backup_to` and `backup_with_wal_to` ([@aster](https://github.com/aster))
- Add WAL/SHM sidecar read, write, and delete to `OpfsPersistentVolume` ([@aster](https://github.com/aster))
- Expose WAL truncate and crash-injection helpers from `yydb-format` ([@aster](https://github.com/aster))
- Record `.yydx` manifest deltas in WAL `BlobRefs` frames ([@aster](https://github.com/aster))
- `checkpoint` writes data pages before committing the header and adds crash-injection probes ([@aster](https://github.com/aster))
- `checkpoint` writes only the inactive header slot for dual-slot alternation ([@aster](https://github.com/aster))
- Sync `YYSH` sidecar mirror after WAL commit ([@aster](https://github.com/aster))
