# YYDB 用户文档

YYDB 是一个单文件本地数据库。一个 `.yydb` 文件同时保存页数据、WAL 伴生文件引用与版本化的 VOS schema 文档。应用通过 VOS 读写，不经过 SQL，也不需要常驻数据库服务。

本套文档面向使用 YYDB 的开发者，不讨论内部实现。所有示例均可在 Node.js 18 或更高版本直接运行。

## 选择入口

| 运行环境 | 入口 | 说明 |
|----------|------|------|
| Node.js 应用 | `@yydb/yydb` | 进程内直接打开文件，含 CLI |
| 浏览器 | `@yydb/light-db` | WASM 会话，持久化到 OPFS |
| 已运行的本地服务 | `@yydb/yydb-client` | WebSocket 或 TCP 二进制帧 |
| Rust 宿主 | `yydb` crate | `Connection`、`client` 与 `server` |

## 边界

- YYDB 不提供 SQL 入口。SQLite 文件只能通过 `@yydb/sqlite` 以只读快照方式读取。
- YYDB 不提供登录、租户、角色、审计或集群。这些能力属于 YYDS。
- `yydb serve` 默认只绑定 `127.0.0.1:7700`，且没有任何身份校验。
- ANN 索引尚未发布，不能作为生产依赖。
