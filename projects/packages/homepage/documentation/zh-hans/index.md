# YY 系文档站（本仓库随 YYDB 发布）

前端与 WebUI 共用 `@yydb/yydb-client`，只认识 **YY 二进制协议 + VOS**。 帧头 `YYDB`/`YYDS` 是后端自称（效果相同，前端不强求一致）。

| 产品     | 定位                                                          |
|----------|---------------------------------------------------------------|
| **YYDB** | 轻：单文件嵌入；无内置权限/审计/上报；本仓库参考 `yydb serve` |
| **YYDS** | 重：分布式大客户；**默认**内置权限、自动审计、调优上报等      |

文档页可做本地帧编解码演示，默认 **不会**连接 live serve。
