# `yydb-pyo3`

Thin PyO3 binding for Python hosts. Engine logic lives in [`yydb`](https://crates.io/crates/yydb); serve loops through [
`yydb-server`](https://crates.io/crates/yydb-server).

Python application authors use the published wheel / binding package, not this crate directly.

[YYDB overview](https://github.com/yy-database/yydb.rs)
